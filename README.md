## 🚀 Projetos em destaque

### 📚 [Librarian](https://github.com/ViniciusSJV/librarian)

Um bibliotecário de evidências desenvolvido em Rust, inspirado no Bibliotecário de *Snow Crash*.

O objetivo é organizar informações, preservar suas fontes e construir consultas rastreáveis, permitindo verificar de onde vêm as afirmações utilizadas por uma IA.

A arquitetura separa duas responsabilidades:

> **Graph Engine → testa sem explicar.**
>
> **LLM Engine → explica sem interpretar.**

O Graph Engine trabalha com referências, linhas, hashes e registros de captura. A camada de IA utiliza as evidências recuperadas para investigar, explicar e propor hipóteses, sem substituir a validação.

### 🎨 [Renderer](https://github.com/ViniciusSJV/renderer)

Motor de Ray Tracing desenvolvido em Rust, baseado no livro *The Ray Tracer Challenge*, de Jamis Buck.

Além de estudar os fundamentos da renderização gráfica, utilizo o projeto como laboratório para experimentar algoritmos, otimizações de CPU e técnicas de medição de desempenho.

Também é um dos principais projetos utilizados para explorar a aplicação do Librarian em problemas reais de engenharia de software.
